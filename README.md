# Emily Sigmund – Yoga Instructor Website

This repository contains the source code for a simple one‑page website for **Emily Sigmund**, a yoga instructor.  
The site is built using plain HTML and Bootstrap for styling.

## 🚀 Features
- One‑page layout
- Header with navigation
- Hero section with image and intro text
- Contact form with name, email, and message fields
- Fully responsive using Bootstrap 5

## 🛠️ Technologies Used
- HTML5
- Bootstrap 5 (via CDN)
- GitHub for version control
- Google Cloud Storage (planned) for hosting
